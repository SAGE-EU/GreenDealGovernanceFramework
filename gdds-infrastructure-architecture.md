# GDDS Architecture & Implementation

This section displays the GDDS technical architecture within the GDDS Frameworks that hold the authoritative description. The GDDS architecture, including the diagram, is set out in D2.1 (see below). The GDDS first version report on realisation of components built, the standards adopted, and their deployment and validation, is documented in D3.1 (GDDS first version report), in particular the architectural overview in Section 3 and the development of the initial version in Section 4.

These deliverables and the GDDS Frameworks serve different purposes and are intended to be read together: D2.1 and D3.1 describe how the GDDS is designed and implemented, while the subsections here express the architecture only at the level needed to support the Business, Governance, Operational and Legal frameworks. Hence, D2.1 and D3.1 are cross- referenced across these sections.&#x20;

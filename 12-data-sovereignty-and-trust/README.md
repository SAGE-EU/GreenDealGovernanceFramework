# Data Sovereignty & Trust

{% hint style="warning" %}
_This section might be updated based on the latest developments in the SAGE consortium, specifically considering WP2, WP3, WP4, and WP5 working groups. Since the project runs till 2028, the final GDDS deliverable is expected to have additional information on these sections._
{% endhint %}

This area brings together the technical capabilities that make data sovereignty operational in the GDDS: Identity & Attestation Management establishes who participants are and how their credentials are issued, enriched, and verified; the Trust Framework defines the mechanisms through which verified participants and services can be trusted across organisational boundaries; and Access & Usage Policies Enforcement turns agreed conditions into machine-readable policies applied at runtime. The governance rules these capabilities implement reside in Data Sovereignty & Technical Governance (Governance Frameworks); this section specifies the technical mechanics, in line with D3.1 (WP3) for the implemented components.

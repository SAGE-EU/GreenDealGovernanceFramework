# Use Cases

{% hint style="warning" %}
_This section might be updated based on the latest development in the SAGE consortium, specifically considering D6.1 and D6.2 by the WP6 - Use Case Demonstration working group. Since the project runs till 2028, the final GDDS deliverable is expected to have additional information on these sections._
{% endhint %}

Use cases are the anchor points of any Data Space; they provide a concrete reason for stakeholders to participate and collaborate. &#x20;

Each use case should be mapped along:&#x20;

* Stakeholders and data types (who needs what data, and why)&#x20;
* Data flows and value exchanges&#x20;
* Business and sustainability outcomes&#x20;
* Scalability and replicability potential&#x20;
